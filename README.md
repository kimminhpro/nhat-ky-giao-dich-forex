## Đưa lên GitHub Pages

1. Tạo một repository mới trên GitHub và tải toàn bộ thư mục này lên nhánh `main`.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**, nhánh `main`, thư mục `/(root)`, rồi bấm **Save**.
4. Mở đường dẫn GitHub Pages được cấp. Trên iPhone: mở bằng Safari, bấm **Chia sẻ → Thêm vào Màn hình chính**.

> Dữ liệu không đồng bộ giữa các thiết bị. Hãy dùng mục **Xuất dữ liệu JSON** trong Cài đặt để sao lưu định kỳ.
